# Nako

Phase one of the Nako taxi-rank network: a public introduction, an installable app for finding taxis, kombis, and coaches in Botswana, and an association dashboard for routes and anonymous usage.

The installed app is the full finder. The website in a normal browser explains the product and asks people to install it. Vehicle positions are simulated until trackers are fitted.

Association staff sign in at `/admin/`. Passengers do not create accounts.
